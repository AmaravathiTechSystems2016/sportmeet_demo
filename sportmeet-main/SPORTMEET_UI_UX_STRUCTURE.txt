2. PRODUCT SUMMARY

SportMeet is a sports venue and event marketplace.

Primary user goals:
- Discover sports venues
- Book courts/time slots
- Browse and join events
- Explore sports categories
- Register as a player or venue owner
- Manage personal bookings
- Allow venue owners to manage their venues and bookings
- Allow admins to manage the full platform

Core product promise:
"Discover, Book & Play."

The app currently has three main role experiences:
1. Public/player experience
2. Venue-owner experience
3. Admin dashboard experience

Book Venues:
- Fetches /api/venues/?status=approved&limit=8
- Displays horizontal venue cards
- Each card includes venue image, venue name, city, rating, ID, and View & Book button
- Links to /venues/:id

Upcoming Events:
- Fetches /api/events/?limit=6
- Displays event image, date, title, host, time, location, price, and sport
- Links to /events/:id

Select Sport:
- Fetches /api/venues/sports/
- Displays sports category image cards
- Links to /venues?sport_category=<sport>

Who We Are:
- Text content currently hard-coded in HomePage.js
- Image comes from siteSettings.who_we_are_image

UX notes:
- Homepage is now data-backed and has fallbacks.
- The header currently appears visually repeated/overloaded in the user's screenshot. This should be reviewed in Header.js and FloatingMenu.js.
- Hero layout currently uses a split text/image layout. It works, but a stronger marketplace UI could use a full-width visual hero with search over image.
- Sections should always show demo cards instead of error-only text where possible.

Recommended homepage improvements:
- Reduce duplicated nav text.
- Use one clean sticky header.
- Make search prominent and connected to venue listing.
- Add category shortcut chips under search: Badminton, Football, Tennis, Basketball, Cricket.
- Add "Popular near you" or "Featured venues" label.
- Add trust stats: venues listed, bookings made, events hosted.
- Replace generic Who We Are text with shorter marketplace copy.
- Add CTA strip for venue owners.

19. PAGES THAT SHOULD NEVER LOOK EMPTY

Homepage:
- Always show featured venues, upcoming events, sports categories, and CTA content.

Venues:
- If filters return no results, show recommended popular venues and a clear "Clear filters" button.

Venue detail:
- Always show image, address, sports, courts, availability placeholder, and contact info.

Events:
- If no events match search, show upcoming featured events and "clear filters".

Event detail:
- Always show cover image/fallback, event details, organizer, location, capacity, and registration status.

Sports:
- Always show sports categories. If API fails, show fallback seeded sports.

User dashboard:
- If user has no bookings, show "Book your first venue" and recommended venues.

Venue owner:
- If no venues, show onboarding checklist and "Create venue".

Admin:
- If no data, show setup checklist and seed/demo status.
